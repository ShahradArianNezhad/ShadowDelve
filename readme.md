# ShadowDelve
a demo made to showcase the abilities of the Vireon game engine and its ease of use

## Requirements
- C++20
- OpenGL
- FreeType

## Compiling And Running
```bash
git clone https://github.com/ShahradArianNezhad/ShadowDelve
cd ShadwoDelve
cmake -B build && cmake --build build
./shadowDelve
```
